# Telegram video downloader

Бот принимает одну ссылку и возвращает видео из YouTube/Shorts, Instagram Reels/публикаций и публичных постов Threads. Из публикации отправляет до 5 видео; фото не отправляются. Длительность — до 30 минут. Большие файлы преобразуются в H.264/AAC MP4 до 48 МиБ для стандартного Telegram Bot API.

Для YouTube перед скачиванием показываются кнопки 360p, 720p и 1080p. Выбранное разрешение — верхняя граница: если его нет у источника, выбирается ближайшее ниже. При превышении лимита размера файл сжимается. Кнопки принадлежат отправителю и действуют 15 минут; следующая ссылка YouTube заменяет предыдущий выбор.

Видео хранятся на сервере временно, во время обработки и отправки. После завершения или ошибки папка запроса удаляется. При принудительной остановке оставшиеся папки очищаются при следующем запуске сервиса. Копия отправленного видео остаётся в Telegram.

Перед отправкой бот считывает размеры и длительность готового файла через ffprobe, передаёт их Telegram явно и прикладывает JPEG-превью с теми же пропорциями. При конвертации нестандартные пиксели и поворот нормализуются без обрезки кадра, чтобы отображение не зависело от обработки этих метаданных клиентом Telegram.

## Статистика владельца

`ADMIN_USER_ID` задаёт единственного владельца статистики. Доступ работает только в личном чате с ботом; проверяются и команды, и кнопки.

- `/stats` — сводка: пользователи, запросы всего/сегодня/за последние 7 дней, результаты, отправленные видео, площадки.
- `/stats users` — пользователи, имена, username, Telegram ID, число запросов и время первого/последнего обращения.
- `/stats recent` — история запросов со временем, пользователем, площадкой, качеством YouTube и результатом.
- `/stats 139640926` — история отдельного пользователя.
- Для списков можно дописать номер страницы: `/stats recent 2`. Под сообщениями также есть кнопки навигации.

Время показывается по Москве. Запрос учитывается после принятия загрузки в очередь; для YouTube — после выбора качества. Отклонённые ссылки, повторные нажатия, отказы из-за занятой очереди и команды в число загрузок не входят. Пользователи учитываются по `/start` или обращению с текстом; первый/последний визит относится к наблюдаемой активности после внедрения статистики. История до внедрения недоступна.

SQLite хранит ID, актуальные имя/username, время, площадку, выбранное качество, число отправленных видео и статус. Исходные ссылки и видео в базу не записываются. Незавершённые запросы после перезапуска отмечаются как прерванные (или частичные, если уже отправлено видео).

Локальный путь по умолчанию: `data/stats.sqlite3`. На сервере `STATS_DB_PATH=/var/lib/tg-video-down/stats.sqlite3`; эта база сохраняется при обновлении кода и не должна удаляться с временными папками. Для резервного копирования используйте SQLite backup API либо копируйте базу при остановленном боте. База исключена из Git. Для нового сервера задайте `ADMIN_USER_ID` и абсолютный `STATS_DB_PATH` в `/etc/tg-video-down.env`.

## Локальный запуск

Нужны Python 3.11+, FFmpeg/ffprobe и Deno 2.3+ для JavaScript-проверок YouTube.

```sh
python -m venv .venv
# Linux: source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Заполнить BOT_TOKEN
python bot.py
```

В `.env` можно указать `ALLOWED_USER_IDS` через запятую. Свой Telegram ID показывает `/start`. Пустой список разрешает пользоваться ботом всем. `COOKIES_FILE` — путь к cookies в формате Netscape, если сайт требует авторизации. Не добавляйте cookies или секреты в Git.

## Сервер

Код: `/opt/tg-video-down`. Окружение: `/opt/tg-video-down/.venv`. Секреты: `/etc/tg-video-down.env` (root, 0600). Сервис запускается от отдельного пользователя `tgvideobot`; временные файлы автоматически удаляются после запроса. Обработчики работают в отдельных процессах, таймаут убивает и скачивание, и дочерний FFmpeg. Параллельно обрабатываются два запроса, очередь ограничена шестью пользователями.

```sh
systemctl status tg-video-down
journalctl -u tg-video-down -n 50 --no-pager
systemctl restart tg-video-down
```

Unit-файл: `deploy/tg-video-down.service`. Для обновления кода скопируйте файлы в `/opt/tg-video-down`, обновите зависимости внутри venv и перезапустите сервис. При изменении сайтов может потребоваться обновить yt-dlp: `.venv/bin/pip install -U 'yt-dlp[default]'`.

## Ограничения

Поддержка ссылок не гарантирует доступность каждого ролика. YouTube может ограничивать IP дата-центров и требовать cookies/PO token; Instagram — авторизацию. Закрытые, удалённые, платные и защищённые DRM материалы не поддерживаются. Threads использует отдельный обработчик встроенных данных страницы; изменение разметки платформы может потребовать его обновления. Короткие ссылки Threads должны разрешаться в канонический пост, иначе бот просит другую ссылку, чтобы не отправить чужое видео из рекомендаций.

Проверки: `pip install pytest && python -m pytest -q`.
